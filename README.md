# L'Artisan Plombier Morbihannais

Site statique (HTML/CSS/JS, sans build) du réseau d'artisans plombiers dans le Morbihan (56).

## À compléter avant la mise en ligne

- **Nom de domaine** : les URL canoniques, le `sitemap.xml` et `robots.txt` utilisent l'adresse provisoire
  `https://plombier-morbihan.netlify.app`. À remplacer par le vrai domaine.
- **Mentions légales** (`mentions-legales/index.html`) : champs `[À COMPLÉTER]` (raison sociale, SIRET, assureur, médiateur).
- **Suivi Google** : Google Tag Manager, Google Ads et la validation Search Console ne sont pas installés
  (identifiants propres à ce site à ajouter).
- **Formulaires** : envoyés via FormSubmit vers Artisangirondin33@gmail.com ; un e-mail d'activation
  FormSubmit sera envoyé au premier envoi depuis ce site.
- **Logo** : `images/logo.svg` est un logo provisoire.
